Wall panel setup

Only the sections you change are applied; everything else stays as it is.

Home Assistant

Your password is only used once to log in and is not stored on the panel. Tip: create a separate, non-admin Home Assistant user for the panel.

MQTT

Controls and sensors in Home Assistant (MQTT discovery). Without MQTT the panel is a plain kiosk, managed over SSH.

SSH access

User admin, port 22. Needed for maintenance and for the rescue mode (USB).

A key is safer than a password; with a password, keep the panel off untrusted networks.

Radio module

The built-in Zigbee/Thread chip. Thread: Thread border router for Home Assistant (Matter over Thread). Zigbee: coordinator for ZHA or Zigbee2MQTT. Off: the chip is not used.

Sensors

Off: the screen only turns on when touched, at a fixed brightness.

Services

Turn off what you don't use to save CPU time and memory.

Two-factor authentication

Done

    Your new private SSH key. Save it now: the panel does not keep a copy. Use it with ssh -i px30-panel-key admin@<panel>.
